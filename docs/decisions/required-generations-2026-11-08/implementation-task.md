Never recover keys from unrelated/current generation, external maps, a callback, local files/KMS or guessed rewraps.
5. **All selected required wraps.** Reject any required generation in unavailable_generations or without the effective entry. Preflight compatible decoded sizes/bounded bytes. One successful version does not cover another version on the same generation. All required keys remain privately owned for the proof; at most one credential plaintext exists at a time.

On failure, local map/temporary owners unwind normally and wipe owned key/plaintext allocations. Return no map/count/prefix proof.

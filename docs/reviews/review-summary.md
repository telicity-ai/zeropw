# ZeroPW 문서 개정 반영 현황

작성일: 2026-09-12 · 의도 정렬 검토 후 수정

## 1. 이번 개정

2026-09-12의 Claude Opus 단일 검토 판정은 REVISE였다. 이번에는 사용자가 승인한 제품 설명에 맞춰 제품·보안·하네스 본문과 PDF를 수정했다. 앞부분의 교정 문구만 덧붙이는 대신 현행 설계를 본문 전체에 반영했다.

| 검토에서 지적한 차이 | 개정 내용 |
| --- | --- |
| 작업별 등록을 요구하던 UX | 서비스 연결과 권한 설정 뒤 지원 CLI·API를 작업별 등록 없이 사용하도록 정의했다. |
| 이전 실행 계약이 남아 있음 | 비밀 없는 CLI 실행, HTTP 인증 중계, SSH 서명 위임과 연결 기반 도구 계약을 작성했다. |
| SSH를 후속 기능으로 미룸 | SSH 서명 위임을 첫 버전의 핵심 기능표와 보안·하네스 수용 조건에 포함했다. |
| 지원 범위 판정 기준 부재 | 프로토콜별 조건과 검증 기준을 추가하고, 미지원이면 평문 주입 없이 실패하도록 명시했다. |
| 사용자 승인과 어댑터 승인의 혼동 | 연결·권한·만료에 대한 사용자 결정과 통합 코드·산출물에 대한 릴리스 검증을 구분했다. |
| 이전 내용을 담은 PDF | 현행 문서로 다시 생성하고 인증 중계·서명 위임 구조와 개정일을 반영했다. |

## 2. 검토 기록의 해석

이번 수정의 근거는 docs/reviews/2026-09-12-intent-alignment-once.md에 보존한 검토 1회다. 수정 후 새 Opus 검토를 수행하거나 PASS를 받은 것으로 표시하지 않는다. 문서 일치 여부와 PDF 출력 확인은 구현 보안 시험과 구분한다.

9월 11일 설계의 검토 기록과 기존 PASS는 당시 입력에만 적용된다. 변경 전 문서·PDF는 docs/archive/2026-09-12-before-auth-delegation에 보관했으며 현행 요구사항으로 사용하지 않는다.

## 3. 남은 구현 과제

실제로 사용할 서비스·CLI를 선정하고 HTTP 인증 위임과 SSH 목적지 검증의 호환성을 시험해야 한다. 클라우드 제공자·리전·예산과 하네스 모델 접근도 구축 전에 확정한다. 제품과 하네스는 아직 배포되지 않았으며 이 문서는 현재 합의한 제품 방향과 구현 수용 기준이다.

## New finding
**ZPCHEAD-OPUS-R1-01 (HIGH, static reasoning, not executed).** A single insider can halt the whole environment. `checked_cache` requires each cached author's record to equal the *current* first verified registry record (`compaction_heads.rs:395`), and it now runs at every eligible receipt, deferred release, local commit and authorized fact signing. The fingerprint is SHA-256(sign_pub) only, and `verify()` only checks the self-signature over agree_pub. So whoever holds the key of a cached author Y can mint Y′ with a new agree_pub.

The attack:
1. Y authors `Y:n` with `member.add(X)`. Receipt accepts it even when fold skips it.
2. X sends `X:1` with HLC `1-0000`. Seq 1 gets no HLC check, and past clocks are accepted. It carries `member.add(Y′)` and sorts first in the registry.

From then on, every author's exactly-next receipt returns `team_compaction_head_invalid`. `handle_commit` errors and ends the session loop. `advance_env` fails each tick while a next commit is deferred and due, so dial and VECTOR stop. Every `author_commit` and every authorized fact fails, including the admin's `member.remove` and `member_removed` against the attacker. Compaction is refused for good.

The existing test (`tests/team_compaction_heads.rs:1593-1700`) sets up this exact earlier-arrival case, with X already removed, but it asserts only compaction refusal and Y's own receipt error. At 04c7d22 the same conflict could only refuse compaction. The Astra decision chose "earlier conflicting arrival ⇒ invalid", but its residual analysis covers only compaction refusal and local corruption, not an insider-triggered halt of receipt and signing that also blocks remediation.

Impact is availability only: no secret or authority exposure, no unlink or data loss, and vault reads are unaffected. The only recovery is deleting the cache by hand, which is undefined procedure. The required change goes to an Astra decision: make the first record immutable at receipt, OR confine the conflict to a compaction-only refusal by validating cached heads against an equal retained announcement, OR document the halt with a defined operator outcome. Add the real-path tests listed in `report.json`.
